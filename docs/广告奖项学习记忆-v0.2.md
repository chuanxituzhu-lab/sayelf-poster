# 广告奖项学习记忆 v0.2

状态：Curated / 可用于本地生成器

当前机器记忆版本：v0.5

本记忆不是获奖作品图库的复制品，而是从官方获奖档案、官方评审趋势和奖项规则中抽取的“可迁移创意机制”。系统保留来源与观察，生成时只使用机制、匹配信号和质量门槛。

## 本轮学习来源

### 国际

- D&AD 2025 Annual、Work Archive 与 Jury Trends：关注概念、字体/图像关系、平台行为、品牌识别、写作工艺、情绪连接。
- Cannes Lions 2025 官方获奖公告与 The Work：关注功能变体验、产品属性驱动叙事、文字与角色的工艺、文化影响与目的。

### 中国

- 中国广告协会 / 中国国际广告节·中国广告长城奖官方规则、获奖名单发布和终审信息：关注原创性、传达清晰、制作精良、传播效果、AI/整合/互动/场景营销、社会责任、精准定位、商业价值与合规。

## 已沉淀机制

| 机制 | 适用问题 | 生成器动作 |
|---|---|---|
| 概念先行 | 画面好看但说不清为什么这样做 | 先生成一句中心概念，再让标题、图像处理和版式证明它 |
| 功能变体验 | 功能或服务容易变成参数表 | 把真实痛点转成可见、可感受、可参与的视觉动作 |
| 品牌真相 | 画面换个品牌也成立 | 把产品独有属性变成标题和主视觉的证据 |
| 媒介即创意 | 只做一张图，没考虑传播场景 | 根据平台规则、互动方式和用户行为改变构图与 CTA |
| 人文连接 | 只有口号，没有情绪关系 | 先建立人物、关系或具体生活细节，再出现品牌/行动 |
| 在地语境 | 国际风格套用到中文场景后失真 | 检查中文语义、地方经验、社会议题和文化合规 |
| 证据化主张 | 广告承诺夸张或无法核验 | 将效果型表述标记为待核验，优先使用可执行动作 |

## 升级原则

1. 只记录官方可追溯来源，不把单个作品的识别性形式当作模板。
2. 新机制必须可迁移到多个主题、平台或媒介。
3. 新机制必须有正向样例、反例和回归测试。
4. 用户反馈可以调整机制权重，但不能覆盖原创、版权、广告法、公众品味和结构化输出门槛。
5. 直接发布率下降时，先调机制匹配和评分权重，再考虑增加风格模板。

## 平台适配与吸睛

- 小红书：使用 3:4 系统预设；以官方内容审核要求为硬门槛，检查封面/标题与正文一致、原创/授权、无其他平台水印和文字规范。
- 公众号：使用 900×383 的 2.35:1 运营预设；公开官方当前文档未确认统一像素硬门槛，因此发布前必须看编辑器裁切预览。
- 抖音：新增 1080×1920 的 9:16 竖屏预设；遵守官方图片分享比例范围、水印和审核约束。
- 通用横版视频：保留 16:9 预设，不冒充某个单一平台的官方规格。

“吸睛分”是 0-10 的自动代理指标，综合标题长度、具体结果/冲突/数字、主体聚焦、视觉差异、平台安全区和内容一致性；它用于筛选第一眼注意力，不承诺爆款。

## 海外平台规则记忆

- YouTube Thumbnail：官方资料建议 16:9，并要求高分辨率、文件大小和社区准则检查。
- TikTok Cover：官方广告资料明确支持 9:16 竖屏；封面仍需根据具体内容类型检查 UI 安全区。
- LinkedIn Post：官方帮助页给出 1.91:1 / 1200×627 的分享图建议，并说明裁切范围。
- Pinterest Pin：官方资料建议图片 Pin 使用 2:3，并强调高质量、可保存主题和安全区。
- Instagram Feed / Story：保留官方帮助入口，但当前公开入口无法稳定读取统一像素硬门槛，因此系统将其标为运营预设，发布前以平台预览为准。

## 素材库与负熵

每次生成可以将成片存入本地 `data/material-library.json`，上限 20 张，分为“可直接发布 / 候选优化 / 实验探索”。系统记录平台、语言、创意机制、奖项对标分、硬门槛、秩序分和下一步调整。这里的“负熵”是工作流定义：把不确定的图像结果压缩成结构化、可复用、可比较的设计资产，降低下一轮迭代的不确定性。

## 奖项体系桥接

`award-bridge-v0.5` 分别对比国际广告奖项的概念、文案、艺术指导、字体与排版、媒介、影响和差异性，以及中国广告评价体系的创意质量、传播效果、本土语境、技术与场景创新、社会责任和合规。对标分只用于内部筛选、复盘和递归进化，不等同于评委真实评分。

当 Prompt 没有明确命中某个风格或机制时，系统默认使用“概念先行”，不会因为某个风格的基础分高就自动套用广告大片；只有用户明确提出“大片、电影级”等信号时才切换到电影级尺度。

## 读书百遍式蒸馏循环

`读官方样片/规则 → 拆概念、文案、视觉、媒介和影响 → 跨来源验证 → 替换对象与语境创新 → 平台缩略图测试 → 记录正反例与回归结果 → 调整记忆权重`
