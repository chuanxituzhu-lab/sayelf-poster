# 构图层蒸馏报告 v0.6

本轮工作以 `chuanxituzhu-lab/sayelf-poster` v0.5 为基础，横向蒸馏 GitHub 上的开源海报设计工具，
提炼可迁移的构图与几何能力，并在原有无 API、可解释规则的设计边界内落地、验证与优化。

## 1. 基础版本盘点（v0.5）

- 流水线完整：输入分析 → 创意机制/风格匹配 → 图像处理计划 → 三候选生成 → 硬门槛+评分 →
  奖项对标 → 素材库归档 → 负熵记忆 → SVG 导出。
- 排版模块 Type Fit v0.5 已含 WCAG 对比度计算、字号/字距/安全区与可读性门槛。
- 短板：`layout` 只是 5 个字符串（left-copy / bottom-copy / …），SVG 渲染坐标全部硬编码，
  三个候选的实际版式差异很小；字号使用零散经验系数，缺少几何依据。

## 2. 横向蒸馏对象

在 GitHub 上检索并比较了多个开源海报/社交卡片生成器，重点分析：

- **greggman/gdp-gen（Graphic Design Poster Generator）**：最具参考价值。其架构把
  `color / layout / typography / compositions` 分层，提供 49 个命名构图、规则化网格几何
  （rule-of-thirds、golden split、modular scale）以及“对比度保证 + bleed 文字背板”的可读性策略。
- **Mendiak/plaintext**（极简排版壁纸）、**map-poster 类工具**：印证“命名构图 + 少量强排版规则”
  是无 AI 场景下产出高质量海报的高杠杆做法。
- 其余多为薄封装或纯 AI 生图前端，可迁移的结构化设计逻辑有限。

## 3. 蒸馏出的三条可迁移原则

1. **命名构图库**：把版式从不可解释的字符串升级为“返回具体放置区的构图函数”。
2. **几何优先的排版**：三分线 / 黄金分割 / 模块化字号阶取代经验系数。
3. **分级对比度**：大号展示型标题可用 WCAG 大文本 3.0 阈值，正文仍守 4.5。

## 4. 本轮落地改动

新增 `src/composition.mjs`（`composition-v0.6`）：

- 几何工具：`GOLDEN`、`THIRDS`、`GOLDEN_SPLIT`、`modularScale(ratio, steps)`。
- 命名构图库 6 个：`编辑三分 / 黄金主视觉 / 居中大字 / 下方承接 / Z 型动线 / 刊头横幅`，
  每个返回 kicker/标题/副标题/footer 的 0..1 分数坐标、锚点与对齐方式，并携带 `imageFocus`
  提示主体位置以便文字避让。
- `pickComposition` 依据风格、机制、平台比例与候选序号确定构图：横向比例强制刊头横幅，
  竖屏优先下方承接，电影级优先黄金主视觉；同一轮三个候选获得不同构图且稳定可复现。

`src/core.mjs`：

- 生成候选时构建 `composition` 并写入 `candidate.composition` 与结构化的 `candidate.layout`
  （含 `regions`、`alignment`、`note`）。
- SVG 渲染器改为读取构图 `regions` 与锚点定位所有文字（含 `text-anchor`），移除硬编码坐标；
  对旧存档候选提供 editorial-thirds 兜底几何。
- `evaluateDesign` 对缺少构图的存档候选自动重建，保证再评分一致。
- 版本号统一升到 0.6，导出 `listCompositions`。

`src/typography.mjs`：

- 引入 `AA_NORMAL=4.5`、`AA_LARGE=3.0`；标题落在 3.0–4.5 大文本区间时打分改为轻惩罚（−12），
  低于 3.0 仍重惩罚（−25）。
- 消费构图的模块化字号阶与 `scaleRatio`，让黄金主视觉/居中大字等版式合理放大标题；
  对齐方式来自构图。
- 新增 `passesContrastFloor`（≥4.5 才为 true）。

`core.mjs` 硬门槛：可读性门槛同时要求打分 ≥70 且 `passesContrastFloor`，
即自动发布仍守 4.5 底线，保守且符合 WCAG。

`src/cli.mjs`：新增 `compositions` 命令列出全部构图。

## 5. 验证结果

- 单元测试从 13 增至 17，全部通过：新增覆盖“候选构图差异化、横向平台强制刊头、
  电影级选黄金主视觉、居中构图渲染出居中文字”。
- CLI/服务器端到端冒烟通过；示例 `xhs_cover` 仍产出 L3、publishScore 93 的成片。
- 抽样渲染四种构图并栅格化核对：版式差异明显、锚点/装饰条/footer 带定位正确
  （CJK 预览字形缺失仅为本地栅格工具限制，SVG 文本本身正确，浏览器/WebUI 正常显示）。

## 6. 设计边界与后续

- 保持无 API、可解释、可回归：仅新增规则与几何，不引入外部模型或获奖作品复制。
- 后续可迁移的下一步：文字换行/缩排以消化 `region.maxWidth`、更多命名构图、
  以及把 `imageFocus` 接入真实图像显著性以进一步自动避让主体。
